        <div class="page-container">
            <h2>Understanding Microcontroller Boards & Hardware Pins 🧠</h2>
            <p class="section-paragraph">
                A microcontroller board (such as an Arduino Uno, ESP32, or STM32 Nucleo) is a self-contained embedded computer packaged onto a printed circuit board (PCB). Unlike desktop computers designed for general software, microcontrollers are engineered to execute dedicated firmware programs in continuous real-time execution loops. At their core lies an integrated silicon package housing the Central Processing Unit (CPU), internal Flash memory for code storage, SRAM for dynamic runtime variables, and specialized hardware peripherals.
            </p>
            
            <p class="section-paragraph">
                To interact with the physical world, microcontroller boards feature exposed hardware header pins grouped into specific electrical functional categories:
            </p>

            <div class="info-grid">
                <div class="info-box">
                    <h3>🔌 Power & Ground Pins (VCC, 5V, 3.3V, GND)</h3>
                    <p>Power pins deliver regulated electrical current to external modules and integrated chips. The 5V and 3.3V pins provide stable operating voltages, while the GND (Ground) pins establish the common zero-volt reference node necessary to complete electric circuit paths across all connected hardware components.</p>
                </div>
                <div class="info-box">
                    <h3>🔘 Digital Input / Output (GPIO) Pins</h3>
                    <p>General Purpose Input/Output pins operate in binary logic states: HIGH (3.3V/5V) or LOW (0V). When set as outputs, they send control signals to switch LEDs, transistors, and relays. When set as inputs, they read high-speed binary state changes from push buttons, motion detectors, and limit switches.</p>
                </div>
                <div class="info-box">
                    <h3>📈 Analog Input Pins (ADC Channels)</h3>
                    <p>Microcontrollers feature internal Analog-to-Digital Converters (ADC) that convert continuous analog voltage signals (ranging from 0V up to VCC) into digital numbers (e.g., 0 to 1023 for 10-bit ADCs). These pins sample variable readings from photoresistors, thermistors, and potentiometers.</p>
                </div>
                <div class="info-box">
                    <h3>🌊 Pulse Width Modulation (PWM) Pins</h3>
                    <p>PWM pins emulate variable analog output voltages by switching digital output pins ON and OFF at ultra-high frequencies. By altering the "Duty Cycle" (the ratio of ON time vs OFF time), PWM controls DC motor rotation speeds, dims LED brightness, and positions servo arms.</p>
                </div>
                <div class="info-box">
                    <h3>📡 Serial Communication Pins (UART, I2C, SPI)</h3>
                    <p>Communication pins allow microcontrollers to talk to high-precision external displays, sensors, and secondary microprocessors. UART uses dedicated TX/RX pins, I2C utilizes SDA (Data) and SCL (Clock) bus lines for multi-device hookups, and SPI provides high-speed full-duplex data transfer.</p>
                </div>
                <div class="info-box">
                    <h3>🛡️ Galvanic Isolation & Switching Protection</h3>
                    <p>Directly connecting inductive loads like motors or high-voltage AC mains appliances directly to microcontroller GPIO pins can destroy digital ICs. Galvanic isolation using optocouplers and relays isolates delicate logic chips from high currents, back-EMF spikes, and electrical noise transients.</p>
                </div>
            </div>
        </div>

    <script>
        const container = document.getElementById('canvas-container');
        const scene = new THREE.Scene();

        const camera = new THREE.PerspectiveCamera(45, container.clientWidth / container.clientHeight, 0.1, 1000);
        camera.position.set(0, 30, 60);

        const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
        renderer.setSize(container.clientWidth, container.clientHeight);
        renderer.setPixelRatio(window.devicePixelRatio);
        renderer.shadowMap.enabled = true;
        container.appendChild(renderer.domElement);

        const controls = new THREE.OrbitControls(camera, renderer.domElement);
        controls.enableDamping = true;

        const ambientLight = new THREE.AmbientLight(0xffffff, 2.0);
        scene.add(ambientLight);

        const dirLight1 = new THREE.DirectionalLight(0xffffff, 2.0);
        dirLight1.position.set(20, 40, 20);
        scene.add(dirLight1);

        const dirLight2 = new THREE.DirectionalLight(0x38bdf8, 1.0);
        dirLight2.position.set(-20, -20, -20);
        scene.add(dirLight2);

        const loader = new THREE.GLTFLoader();
        let arduinoModel;

        loader.load(
            "{{ url_for('static', filename='arduino_uno.glb') }}",
            function (gltf) {
                arduinoModel = gltf.scene;
                const box = new THREE.Box3().setFromObject(arduinoModel);
                const center = box.getCenter(new THREE.Vector3());
                const size = box.getSize(new THREE.Vector3());

                arduinoModel.position.x += (arduinoModel.position.x - center.x);
                arduinoModel.position.y += (arduinoModel.position.y - center.y);
                arduinoModel.position.z += (arduinoModel.position.z - center.z);

                const maxDim = Math.max(size.x, size.y, size.z);
                if (maxDim > 0) {
                    const scale = 25 / maxDim;
                    arduinoModel.scale.set(scale, scale, scale);
                }
                scene.add(arduinoModel);
            },
            undefined,
            function (error) { console.error("Error loading model:", error); }
        );

        function animate() {
            requestAnimationFrame(animate);
            if (arduinoModel) { arduinoModel.rotation.y += 0.003; }
            controls.update();
            renderer.render(scene, camera);
        }
        animate();

        window.addEventListener('resize', () => {
            renderer.setSize(container.clientWidth, container.clientHeight);
            camera.aspect = container.clientWidth / container.clientHeight;
            camera.updateProjectionMatrix();
        });
    </script>
